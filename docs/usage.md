# 逐图改名

原生 macOS 图片重命名应用，适用于 macOS 12 及以上，包含 Apple 芯片和 Intel 版本，不需要安装 Python 或其他运行环境。

## 打开与使用

1. 双击同目录的 **逐图改名.app**。也可以将它拖到“应用程序”文件夹。
2. 点击“选择文件夹…”，选择存放图片的文件夹。
3. 图片会按文件名自然排序显示，中央大图自动适应窗口，可以将窗口最大化。
4. 在下方文本框输入新名称，例如 `海边日落`，按 **Return** 或点击“保存并下一张”。名称会直接写回原文件。
5. 用“上一张”“下一张”或左侧列表切换图片。“仅保存”会停留在当前图片。

如果使用 ZIP，请先解压。应用采用本地临时签名，没有 Apple 开发者公证；如果 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中查看对应的“仍要打开”选项。

## 图片预览

- 使用 `−` / `＋` 放大缩小；放大后通过滚动条或触控板滚动查看。
- “适应窗口”完整显示图片；“100%”按图片原始逻辑尺寸显示。支持触控板捏合缩放。
- 常见 JPG、PNG、HEIC、TIFF、GIF、WebP 等格式通过系统识别，实际预览能力取决于 macOS。动画和多页图片仅用于静态预览。
- 只读取所选文件夹的第一层，不包含隐藏文件、子文件夹和符号链接。个别无法解码的图片仍可改名或跳过。

## 文件保护与撤销

- 只改文件名，不重新编码图片；原扩展名及其大小写保留。
- 文本框默认选中当前文件名主体，可直接输入替换。也可以粘贴包含相同扩展名的完整名称。
- 新名称与现有文件冲突时，会阻止操作，不会覆盖文件。在大小写不敏感的磁盘上，只改变大小写的名称也会被阻止；可先改成一个临时名称，再改成目标名称。
- 名称会去掉首尾空白，不接受 `/`、`:` 或控制字符。
- 切换图片、文件夹或退出时，如有未保存输入，会提示保存、丢弃或取消。
- “撤销重命名”可逐次撤销本次文件夹会话中的操作。退出应用或切换文件夹后，撤销历史不保留；已改的文件名仍然保留。
- 图片顺序在本次载入期间固定，不会因改名重新排序。外部增删文件后，请重新选择文件夹刷新。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Return / ⌘ Return | 保存并下一张 |
| ⌘ O | 选择文件夹 |
| ⌘ [ / ⌘ ] | 上一张 / 下一张 |
| ⌘ Z | 撤销上次文件重命名 |
| ⌘ A / C / V / X | 文本全选 / 复制 / 粘贴 / 剪切 |
| ⌘ Q | 退出 |

最后一张保存后会停留，并显示完成提示。所有图片和名称仅在本机处理，不上传网络。

## 源码与构建

仓库内提供完整 Swift / AppKit 源码。安装 Apple Command Line Tools 后，在仓库根目录执行：

```bash
bash scripts/build.sh
```

构建脚本在 `dist/` 输出双架构 `.app`。运行 `bash scripts/test.sh` 执行文件操作测试；运行 `bash scripts/package.sh` 生成安装 ZIP 和 SHA-256 校验文件。
