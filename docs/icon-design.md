# 逐图改名 · 应用图标

蓝绿色圆角底板搭配照片卡片、文件名标签和铅笔，表达浏览图片并修改名称。图标不含文字，便于在 Dock 中缩小显示。

使用内置 image_gen 生成透明 PNG，之后通过 macOS sips 制作多分辨率 PNG，通过 iconutil 封装为 ICNS。AppIcon.icns 已接入 Info.plist 和构建脚本。
